# Privacy and AI Use

## Public vs. private

This GitHub repository is a sanitized portfolio representation. The live School Assistant is private because it processes real school and account information.

The public repository does not contain:

- credentials, tokens, cookies, or browser profiles
- personal Gmail content
- private Google Drive identifiers
- teacher or student contact details
- downloaded school files
- real assessment submissions
- raw automation logs

## What AI does

AI receives a small structured planner dataset and helps:

- prioritize confirmed work
- choose efficient study methods
- compress workload when appropriate
- explain why an item matters
- identify uncertainty and ask for clarification when needed

## What AI does not do

The AI layer is not trusted to invent:

- deadlines
- assignments
- completion status
- source data
- authentication details

Those come from structured evidence or explicit user input.

## AI-assisted development

AI has also been used during development for brainstorming, code review, debugging, refactoring suggestions, and test ideas.

I treat AI as an engineering collaborator rather than an author I blindly copy from. I decide the problem definition, architecture, privacy boundary, acceptance criteria, and whether proposed changes survive testing.

## Safety rule

No private source data should ever be committed to this repository. Sample files use fictional classes and content.
